# 个人作品展厅设计

用户已批准 2026-11-05 对话中的第三种方案并要求开始实现。交付本地静态站，无需再次审批，不执行 Git 操作或部署。

## 目标与范围
- 作品集首页、KnowWeft 子页、Tessera 子页；self_review 和 Creator 作为正在构建项目展示。
- 首页为深午夜色交互展厅，悬浮 3D 核心与明确文字入口。产品页各有独立品牌、真实信息及交互演示。
- KnowWeft：知识树、场景、时间线、可编辑 PPTX；延续经蓝、纬青、陶土色。
- Tessera：Windows 插件工具箱，靛蓝色；演示单位换算和文本处理，准确区分网页体验与桌面功能。
- 中文文案，自适应布局，键盘可访问，减少动态效果支持，无 WebGL 时保留静态视觉。

## 方案决策
比较全站沉浸宇宙、精品产品画廊、交互展厅与独立产品叙事；采用第三种，平衡表现力、信息可读性与扩展成本。
Astro 静态多页 + TypeScript + Three.js，内容与导航保持静态 HTML，3D 延迟加载。独立目录 D:\my\portfolio，既有项目仅作为素材和信息来源。
采用与当前 Node 22.22.2 兼容的 Astro 5 系列并锁定安装版本，不修改系统 Node。

## 模块和数据
SiteLayout 负责元数据、导航、页脚；global.css 管理基础字体、间距与交互；Scene 负责 3D 生命周期和 fallback；三个 pages 各自拥有内容和局部样式；项目元数据集中于 data/projects.ts。
无需后台接口和数据库。演示数据使用本地常量，主题偏好存 localStorage，并处理存储不可用。

## 视觉
首页：#080F1E 背景、#F3F5FB 文字、#A4ADC2 次要文字、#A9B6FF 光色、#75D4C7 织线、#D8B98E 温暖点缀。
字形使用本机 Segoe UI Variable、微软雅黑，标题采用大尺度中英文字对照。单一主视觉、清晰作品展区，避免满页同质卡片。
KnowWeft 保留正式蓝青标志；Tessera 正式标志禁止旋转、改色与外加阴影，动画放在周边模块。

## 验收
构建与类型检查通过，三路由独立返回 200，无内部死链、无横向溢出；交互在桌面与手机工作；无 WebGL、减少动态效果下仍可阅读导航；不存在未支持的功能或发布状态宣传。
